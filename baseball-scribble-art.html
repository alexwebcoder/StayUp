What is Scribble Art?

Scribble art is a hand drawn illustration style built using layered pen strokes to create depth, texture, and detail. In baseball scribble art, each portrait is formed using ballpoint pen drawing techniques that transform classic players into expressive scribble drawings. This scribble drawing style blends realism with artistic texture to create unique baseball art prints.
